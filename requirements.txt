# ── No orchestration framework ────────────────────────────────────────────────
# langchain, langchain-core and llama-index-core were listed here and imported
# nowhere.  Removed rather than adopted: the pipeline is a handful of explicit
# steps in retrieval.py and generation.py, and the parts that carry the product's
# value — basis detection, the unindexed-company gate, provenance folded into the
# indexed text, the abstention decision — are not things either framework models.
# Wrapping them in a chain would add an abstraction layer over the specific logic
# that is the point.
#
# EmbeddingModel does implement embed_documents/embed_query, so it duck-types
# into a LangChain chain if one is ever wanted. That costs nothing and needs no
# dependency.
